# Rules for this repo

- Push every change directly to the main branch. Do not create branches or pull requests.
- Owner is not a coder. Explain every change in plain, simple English.
- App is a single index.html file (HTML + CSS + JS together). Do not split into multiple files.
- JavaScript: use var only. No const, no let, no arrow functions, no template literals.
- Storage: Firebase Firestore. Photos: Cloudinary. Do not change existing Firestore collection/field names without asking.
- Never put API keys or passwords in the code.
- Load ZXing from unpkg, never cdnjs.
- Keep the .nojekyll file. Keep the file name index.html (lowercase).
- Hosted on GitHub Pages. No build step, no npm packages.
- Make the smallest change that solves the task. Do not redesign or rewrite working parts.
- Staff are logged as Staff A / B / C, never by name.
