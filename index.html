Setup Steps
Step 1: Create Google Sheet
Go to sheets.google.com → Click + (New) → Name it "OptiStock Backup"
Step 2: Open Apps Script
Click Extensions → Apps Script → Delete all existing code
Step 3: Paste Script
Saves inventory, sales & purchase orders to your Sheet automatically after each sale.
Step 4: Deploy
Click Deploy → New Deployment → Type: Web app → Execute as: Me → Who has access: Anyone → Deploy → Authorize → Copy the Web App URL
Step 5: Save URL in Settings
✓ After setup, every sale auto-syncs!
You can also manually sync anytime from More → Sync Sheets
