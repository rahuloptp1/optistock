Setup Steps
1. Create Google Sheet
Go to sheets.google.com → New sheet → Name it "OptiStock Backup"
2. Open Apps Script
Click Extensions → Apps Script → Delete all code
3. Paste Script
Script handles: inventory backup, photo upload to Drive, restore, sales history
4. Deploy as Web App
Deploy → New Deployment → Type: Web app → Execute as: Me → Access: Anyone → Deploy → Copy URL
5. Paste URL in Settings
