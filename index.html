🔒 100% Private & Free
Your data goes directly to YOUR Google Sheet. No third-party servers. Free forever. One-time 5-minute setup.
Step-by-Step Setup
1
Create a Google Sheet
Go to sheets.google.com → Click + to create new sheet → Name it "OptiStock Backup"
2
Open Apps Script
In your sheet, click Extensions → Apps Script → Delete all existing code
3
Paste This Script
4
Save & Deploy
1. Click 💾 Save (Ctrl+S)
2. Click Deploy → New Deployment
3. Type = Web app
4. Execute as = Me
5. Who has access = Anyone
6. Click Deploy → Authorize → Copy the web app URL
5
Paste URL in Settings
Go to Settings in More tab → Paste URL in "Google Sheets Web App URL" field → Save
✓ After setup, every sale auto-syncs!
OptiStock will send your inventory, sales and purchase orders to Google Sheets automatically after each sale.
