Step-by-Step Setup
1
Create a Google Sheet
Go to sheets.google.com → Click + → Name it "OptiStock Backup"
2
Open Apps Script
Click Extensions → Apps Script → Delete all code
3
Paste Script & Deploy
4
Deploy as Web App
1. Click Deploy → New Deployment
2. Type = Web app
3. Execute as = Me
4. Who has access = Anyone
5. Click Deploy → Authorize → Copy URL
5
Paste URL in Settings
Go to Settings → Paste URL in Google Sheets Web App URL → Save
